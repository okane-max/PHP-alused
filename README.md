# Autorent - PHP Projekt

## Paigaldusjuhend
1. Klooni projekt veebiserveri juurkausta: `git clone https://github.com/okane-max/PHP-alused.git`
2. Loo MySQL/MariaDB andmebaas nimega `autorent`.
3. Impordi andmebaasi struktuur failist `db/autorent_uuendatud.sql`.
4. Muuda failis `config.php` andmebaasi kasutajatunnused ja parool vastavaks oma serverile.
5. Ava veebisait brauseris aadressil `http://localhost/PHP-alused`.
